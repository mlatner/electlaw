# Framework documents — reading order

This project produces a practitioner-oriented implementation guide
for US state and local PR reform — a much larger and more detailed
follow-up to the Charles Hamilton Houston Institute / Guinier
Project primer *Getting from Votes to Seats*. See `synthesis.md`
for the full mission.

## Reading order

1. **`synthesis.md`** — mission, scope, and how the framework
   documents fit together. **Read first.**
2. **`components/01_seat_product.md`** — Component 1: Assembly Size
   × District Magnitude. Threshold of Exclusion = 1/(M+1).
3. **`components/02_ballot_structure.md`** — Component 2: how voters
   express preferences; coordination problems; spectrum of ballot
   types; non-partisan list labeling.
4. **`components/03_allocation.md`** — Component 3: Hamilton/Hare,
   Droop, Jefferson/D'Hondt, Webster/Sainte-Laguë and others.
5. **`connected_areas.md`** — surrounding statutory and
   administrative environment that affects the mechanics.
6. **`performance.md`** — PROSeS diagnostic tool (James 2020).
7. **`electoral_cycle.md`** — PEI eleven-stage cycle, used as a
   cross-reference checklist.
8. **`case_template.md`** — operationalization. Copy into each
   country case folder as `profile.md`.

## Sources backing the framework

See `sources/sources.md`. Principal references:

- **Charles Hamilton Houston Institute / Guinier Project** —
  *Getting from Votes to Seats* primer (the conceptual foundation).
- Norris / Electoral Integrity Project — temporal cycle.
- James (2020), *Comparative Electoral Management* — PROSeS
  performance criteria.
- Gardner (ed., 2022), *Comparative Election Law* — universal vs.
  particular portability test.
- Venice Commission, *Code of Good Practice in Electoral Matters*
  (2002) — normative floor.
- International IDEA, *Electoral System Design Handbook* + ESD
  Database — typology.
- ACE Electoral Knowledge Network — practitioner taxonomy.
